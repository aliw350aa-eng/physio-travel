# Physio Travel

تطبيق لحجز جلسات العلاج الطبيعي. أي حد معاه الرابط يقدر يسجّل:

- **طبيب:** يعمل حساب، يملأ بياناته وأسعاره ومواعيده، تظهر صفحته للمرضى، يستقبل الحجوزات ويؤكدها أو يعتذر، ويرد على المرضى.
- **حجز جلسة (مريض):** يختار نوع الجلسة والمدينة والدكتور واليوم والساعة، يشوف السعر، يحجز، يراسل الدكتور ويقيّمه.

السيرفر Node.js (Express) وقاعدة البيانات SQLite في ملف واحد، والواجهة عربية RTL بدون خطوات بناء.

## تشغيل على جهازك

```bash
npm install
SEED_DEMO=1 npm start     # SEED_DEMO=1 يضيف ٨ أطباء «نموذج» للتجربة (اختياري)
```

افتح http://localhost:3000

متغيرات البيئة:

| المتغير | الافتراضي | الغرض |
|---|---|---|
| `PORT` | `3000` | بورت السيرفر |
| `DATA_DIR` | `./data` | مكان ملف قاعدة البيانات `physio.db` |
| `SEED_DEMO` | غير مفعّل | `1` يضيف الأطباء النماذج لو مش موجودين |

## نشر على الإنترنت

أي استضافة بتشغّل Node أو Docker تنفع. الشرط الوحيد: **قرص دائم** (Persistent Disk / Volume) تحط عليه `DATA_DIR`، وإلا قاعدة البيانات هتتمسح مع كل نشر جديد.

**Render:** ارفع المجلد على GitHub، وأنشئ Blueprint من الملف `render.yaml` (فيه Docker وقرص ١ جيجا). الخطة المدفوعة مطلوبة عشان القرص الدائم.

**Railway / Fly.io:** اعمل خدمة من المجلد (فيه `Dockerfile`)، وأضف Volume على المسار `/data`.

**سيرفر خاص (VPS):**

```bash
docker build -t physio-travel .
docker run -d --restart unless-stopped -p 3000:3000 -v physio-data:/data -e SEED_DEMO=1 physio-travel
```

ولازم HTTPS قدامه (المنصات اللي فوق بتديه تلقائيًا، وعلى VPS استخدم Caddy أو Nginx). الكوكي بيتفعّل عليه Secure لوحده لما الطلب يجي عبر HTTPS.

النسخ الاحتياطي: انسخ مجلد `DATA_DIR` (ملف `physio.db`) بشكل دوري.

## الأمان: اللي موجود

- كلمات السر متشفّرة بـ scrypt مع salt لكل مستخدم، والجلسات توكن عشوائي بيتخزن مشفّر (SHA-256) في القاعدة وكوكي `HttpOnly` و`SameSite=Lax`.
- كل صلاحية بتتفحص في السيرفر: المريض يشوف حجوزاته ومحادثاته بس، والدكتور يشوف حجوزاته ومحادثاته بس، وتأكيد الحجز للدكتور صاحبه بس.
- السعر بيتحسب في السيرفر من أسعار الدكتور، مش من المتصفح.
- منع الحجز المزدوج على مستوى القاعدة (فهرس فريد على الدكتور واليوم والساعة).
- حماية من الطلبات من مواقع تانية (فحص Origin)، وحدود لعدد المحاولات على التسجيل والدخول والحجز والرسائل.
- ترويسات أمان (CSP وغيرها).

## لسه مش موجود (قبل ما مرضى حقيقيين يستخدموه)

- **توثيق الأطباء:** أي حد يقدر يسجّل كطبيب وصفحته تظهر فورًا. لو هتشتغل بجد، ضيف مراجعة يدوية (مثلًا عمود `approved` وصفحة إدارة) وتحقق من رخصة مزاولة المهنة.
- تأكيد الإيميل، واسترجاع كلمة السر.
- إشعارات (إيميل أو واتساب) عند حجز جديد أو رسالة جديدة. الواجهة بتحدّث نفسها كل ٣ إلى ٥ ثواني.
- الدفع الإلكتروني (دلوقتي الدفع كاش بعد الجلسة).
- حدود الطلبات محفوظة في ذاكرة السيرفر، فتفترض نسخة واحدة من السيرفر. SQLite كمان مناسب لنسخة واحدة.
- سياسة خصوصية وشروط استخدام. الحجوزات فيها أرقام موبايل وعناوين وبيانات صحية، فلازم تتعامل معاها حسب القانون المصري لحماية البيانات الشخصية.
